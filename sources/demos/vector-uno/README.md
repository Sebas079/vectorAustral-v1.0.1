# Vector Uno demos

Esta carpeta concentra los recursos audiovisuales del asistente Vector Uno, creados como material de marketing y demostración del valor de la agencia.

Objetivo:

- mostrar la propuesta de valor de Vector Austral en menos de 60 segundos
- dar una demo utilizable para la landing y presentaciones
- mantener una fuente editable de guion, prompts y versiones finales

Flujo recomendado:

1. generar guion base en scripts/
2. preparar prompts de IA en prompts/
3. validar storyboard en storyboards/
4. exportar render preliminar en renders/
5. revisar y dejar versión final en final/

La versión final se incorpora luego a la web desde public/assets/demos/vector-uno.
