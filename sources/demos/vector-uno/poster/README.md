# Poster y cover

Aquí se almacenan los posters de cada demo para utilizar como preview antes del video o como fallback visual.

Formato recomendado:

- JPG o WebP
- proporción 16:9 o 9:16 según el uso final
- mantener la marca y la identidad visual de Vector Austral

Ejemplo de nomenclatura:

- vector-one-demo-01-poster.jpg
- vector-one-demo-01-cover.webp

Para el MVP, el poster vectorial publicado se encuentra en:
`public/assets/demos/vector-uno/vector-uno-demo-poster.svg`.
