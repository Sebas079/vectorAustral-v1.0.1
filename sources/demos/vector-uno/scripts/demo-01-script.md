# Demo 01 — Vector Uno presenta la agencia

Duración estimada: 30 a 45 segundos.

Escena 1:

- Vector Uno aparece en pantalla como asistente inteligente.
- Mensaje inicial: "Hola, necesito entender tu proyecto y te ayudo a convertirlo en una solución real."

Escena 2:

- Se muestran servicios principales: web institucional, plataformas web, automatizaciones y apps móviles complementarias.
- Vector Uno describe la necesidad del cliente con lenguaje claro y técnico.

Escena 3:

- Se muestra la lógica de acompañamiento: diagnóstico, propuesta, diseño, desarrollo, entrega y soporte.
- El asistente actúa como guía, no como vendedor agresivo.

Escena 4:

- Cierre: "Vector Austral acompaña cada etapa del negocio con tecnología y estrategia."
- CTA: "Hablemos de tu próximo proyecto."

Tone:

- premium
- claro
- tecnológico
- sobrio
- orientado a conversión
