# SKILL: Spec-Driven Development (SDD)

## Flujo de Trabajo Obligatorio

Antes de escribir cualquier archivo de código (`.tsx`, `.ts`, `.js`), debes completar las siguientes fases en la conversación:

### Fase 1: Análisis y Diagnóstico

- Revisa los archivos existentes afectados.
- Explica a Sebas qué vas a hacer y por qué.

### Fase 2: Plan de Cambio (Spec)

- Muestra una lista clara de los archivos que vas a crear o modificar.
- Describe brevemente el impacto en el proyecto.

### Fase 3: Ejecución

- Modifica o crea el código paso a paso.
- Prioriza código limpio, fuertemente tipado en TypeScript.

### Fase 4: Verificación

- Solicita ejecutar la verificación local (`npm run build` o `npm run dev`) antes de dar por terminada la tarea.
